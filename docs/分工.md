## 三、接口约定（14:15 冻结，之后改动需在群里说明）

```python
# src/models.py
Record(id, date, type, amount, category, note, created_at)
Record.to_dict() / Record.from_dict(d) / new_record(...) -> Record

# src/storage.py
load_records() -> list[dict]
save_records(records) -> None
add_record(record) -> dict
delete_record(record_id) -> bool

# src/stats.py
totals(records) -> dict          # {"income":, "expense":, "balance":}
summary(records, start, end) -> dict
daily_totals(records) -> list[dict]

# src/stats_by_category.py
by_category(records, rtype="expense") -> list[dict]   # [{"category":, "amount":, "count":, "ratio":}]
top_categories(records, n=5) -> list[dict]

# src/nl_parser.py
parse_text(text) -> dict | None   # 解析失败返回 None

# src/import_export.py
to_csv(records) -> bytes
from_csv(file_bytes) -> list[dict]

# 页面模块（Streamlit）
render_add_expense() / render_add_income() / render_records() / render_charts(...)
render_data_page(records)
```

## 四、Git 协作流程

```bash
git clone <repo>
git checkout -b feat/qiufuming-expense
# 只改自己负责的文件
git add src/add_expense.py
git commit -m "feat(expense): 支出录入表单与校验"
git push origin feat/qiufuming-expense
# 在 GitHub 发起 PR，黄俊翔合并
```

- 分支命名：`feat/<拼音>-<模块>`。
- 提交粒度：一个功能一次提交，不要 17:00 前一次性提交全部。
- 冲突处理：先 `git pull --rebase origin main`，只解决自己文件内的冲突。
- 公共文件（`app.py`、`src/models.py`、`src/config.py`）由 1 号、2 号维护，其他人不直接改。
