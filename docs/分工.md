## 一、架构与存储

```
web/index.html + web/js/*.js  ──REST──▶  FastAPI app.py
                                              │
                                              ▼
                                    src/storage.py（SQLite3）
                                              │ 每次写操作后
                                              ▼
                                    data/records.json（快照备份）
```

- 主存储：`data/records.db`，表 `records`，`date` / `type` 建索引。
- 首次启动：`records.db` 不存在或表为空时，自动迁移 `data/records.json` 的演示数据。
- 测试兼容：`monkeypatch` 修改 `storage.DATA_FILE` 后，数据库自动落在同目录的 `records.db`，不会污染真实数据。

## 三、接口契约（冻结）

```text
GET    /api/config                 -> {expense_categories, income_categories, record_types, currency,
                                       today, engine, db_file, storage:{engine, db_file, data_file}}
GET    /api/records?type=&category=&start=&end=&keyword=&limit=
                                   -> {records, count, totals:{income,expense,balance,count}, storage}
POST   /api/records                -> 201 {record, totals} | 400 {detail:{errors:[]}}
PUT    /api/records/{id}           -> 200 {record, totals} | 400 / 404
DELETE /api/records/{id}           -> 200 {deleted, totals} | 404
POST   /api/nl-parse               -> {text, auto_save} -> {parsed, saved, totals}
GET    /api/stats?start=&end=      -> {summary, daily_totals, expense_by_category, income_by_category, totals, range}
GET    /api/export/csv             -> text/csv 文件流（UTF-8 BOM）
POST   /api/import/csv             -> multipart file -> {imported, total, totals, engine}
```

字段：`id, date(YYYY-MM-DD), type(expense|income), amount(>0), category, note, created_at`。

## 四、Git 协作流程

```bash
git checkout main && git pull
git checkout -b feat/<拼音>-<模块>
# 只改自己负责的文件
git add <自己的文件>
git commit -m "feat(模块): 具体改动"
git push origin feat/<拼音>-<模块>
# GitHub 发起 PR，黄俊翔合并
```

- 公共文件：`app.py`、`src/models.py`、`src/config.py`、`web/index.html`、`web/js/api.js` 由对应负责人维护。
- 提交粒度：一个功能一次提交，禁止 17:00 前一次性提交全部。
- 冲突处理：`git pull --rebase origin main`，只解决自己文件内冲突。

## 五、状态联动约定

任何写操作（支出、收入、一句话记账、编辑、删除、导入）成功后，调用 `api.js` 的 `refreshApp()`：

1. 重拉 `/api/records` 刷新顶部 4 张指标卡；
2. 广播 `app:changed`，当前激活视图重新取数；
3. `toast()` 在右上角提示。
