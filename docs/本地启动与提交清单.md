# 本地启动与 13 人 Git 提交清单

## 一、环境要求

- Python 3.10 及以上
- 不需要 Node、npm、webpack、vite
- 不需要安装 MySQL / PostgreSQL，SQLite 由 Python 标准库自带
- 浏览器 Chrome / Edge 均可

## 二、一键启动（现场演示版）

```bash
cd expense-book
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

打开 http://127.0.0.1:8000 ，接口文档在 http://127.0.0.1:8000/docs 。

首次启动会自动创建 `data/records.db`，并把 `data/records.json` 中的演示数据迁移进去。之后每次增删改都会同步刷新 JSON 快照。

ECharts 已放在 `web/js/vendor/echarts.min.js`，断网也能出图；本地文件缺失时才回退 CDN。

## 四、每人的提交流程

```bash
git clone https://github.com/H3HN/expense-book.git
cd expense-book
git config user.name "姓名"
git config user.email "学号@fzu.edu.cn"

git checkout -b feat/<拼音>-<模块>
# 修改自己负责的文件，至少做一处可见增强
git add <只 add 自己的文件>
git commit -m "feat(模块): 具体改动"
git push origin feat/<拼音>-<模块>
```

然后到 GitHub 发起 Pull Request，由黄俊翔合并到 `main`。

提交自查：

```bash
git status
git diff --stat main
git log --oneline -3
```

`git status` 里不能出现别人的文件，否则会被判定为越界提交。


- `/api/config` 返回 `"engine": "SQLite3 + JSON Backup"`
- `data/records.db` 与 `data/records.json` 同时存在
- 首页 4 张指标卡有数字
- 记一笔支出后，右上角出现 Toast，顶部指标立即变化
- 明细页编辑一条记录后，表格与指标同步刷新

- 数据页能下载 CSV，拖入同一文件后提示合并条数

重置演示数据（同时清空 SQLite 与 JSON，再重启服务会自动重新建表）：

```bash
python -c "import pathlib;[p.unlink() for p in [pathlib.Path('data/records.db'),pathlib.Path('data/records.db-wal'),pathlib.Path('data/records.db-shm')] if p.exists()];pathlib.Path('data/records.json').write_text('[]',encoding='utf-8')"
```

## 七、常见问题

| 现象 | 处理 |
| --- | --- |
| 端口被占用 | 换 `--port 8001`，或结束占用 8000 的进程 |
| 页面打开是 JSON | 前端未加载，确认 `web/index.html` 存在并重启 uvicorn |
| 图表空白 | 检查 `web/js/vendor/echarts.min.js` 是否存在，F12 看控制台 |
| 导入提示没有有效记录 | CSV 表头需包含 `date,type,amount,category,note` |
| 中文乱码 | 后端导出已带 BOM，Excel 直接打开即可 |
| 数据库锁 | 确认没有第二个 uvicorn 进程同时占用 `data/records.db` |
| 想要纯 JSON 数据 | 直接看 `data/records.json`，每次写操作后都会同步 |
